# Dados

Esta pasta reúne os conjuntos de dados usados nas atividades de classificação de textos.

| Arquivo | Uso |
| --- | --- |
| `classic4.csv` | classificação clássica e classificação com DistilBERT |
| `industry_sector.csv` | classificação clássica e classificação com DistilBERT |

Os arquivos possuem as colunas `file_name`, `text` e `class`.

Os dados foram fornecidos no contexto acadêmico da disciplina. Antes de redistribuí-los publicamente, confirme as condições de uso e licenciamento da fonte original.

O corpus JSON usado na atividade de BPE e o texto usado no experimento original de bigramas não estavam incluídos no repositório enviado. Por isso, os respectivos notebooks possuem exemplos de fallback e instruções para utilização de arquivos próprios.
